# Unpoppable

Unpoppable é um jogo 2D feito em Godot como projeto da cadeira de Programação para Jogos.

O jogador controla Balum, um balão que precisa sobreviver a ondas de macacos inimigos. Conforme elimina inimigos, novas rodadas começam, a dificuldade aumenta e novas armas são liberadas.

## Sobre o jogo

O objetivo é sobreviver pelo maior tempo possível e acumular o maior número de kills.

O jogador começa com 3 vidas. Ao tomar dano, Balum muda de cor para indicar o estado atual de vida.

## Controles

- W / seta para cima: mover para cima
- A / seta para esquerda: mover para esquerda
- S / seta para baixo: mover para baixo
- D / seta para direita: mover para direita
- Mouse esquerdo: atirar
